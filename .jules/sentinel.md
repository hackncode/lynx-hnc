## 2024-05-20 - Fix Weak Random Number Generation in GUIDs
**Vulnerability:** The `guid()` utility in `js_libraries/lynx-runtime-shared/src/utils.ts` was using `Math.random()` to generate UUIDs. `Math.random()` is not cryptographically secure, which means generated IDs could be predictable, posing a security risk depending on how these IDs are used (e.g., session identifiers, secure tokens).
**Learning:** For older runtimes or specific constrained environments, standard `crypto.randomUUID()` might not be available. However, developers must employ graceful degradation by checking for `crypto.randomUUID()` or `crypto.getRandomValues()` before falling back to `Math.random()`.
**Prevention:** Always use cryptographically secure methods like `crypto.randomUUID()` or `crypto.getRandomValues()` when generating sensitive unique identifiers. Check for `typeof crypto !== 'undefined'` to safely handle runtimes where `crypto` might be missing. Avoid `eval` for accessing `crypto` due to CSP constraints.
