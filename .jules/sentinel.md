## 2025-02-18 - Weak Random Number Generation in Shared Utils
**Vulnerability:** Weak random number generation using `Math.random()` in UUID generation within `js_libraries/lynx-runtime-shared/src/utils.ts`. This poses a security risk as the UUIDs generated are predictable and might be used in a security-sensitive context.
**Learning:** `crypto.randomUUID()` and `crypto.getRandomValues()` should be used for cryptographically secure pseudo-random number generation. In the specific context of this project, we must pre-allocate the byte array for `getRandomValues` due to performance constraints, avoid ES2017 string methods for backward compatibility, and fallback to `Math.random()` only when the crypto API is entirely unavailable. Feature detection of the `crypto` API must be done via `typeof crypto !== 'undefined'` rather than an `eval` technique due to CSP restrictions.
**Prevention:** Use the `crypto` module (via proper feature detection) for UUID generation where possible, with a gracefully degradable fallback structure.
