## 2024-03-21 - [Weak Pseudo-Random Number Generation]
**Vulnerability:** Weak random number generation using `Math.random()` in the UUID generation function `guid()`. `Math.random()` is not a cryptographically secure pseudo-random number generator, which can result in predictable UUIDs if used for security-sensitive operations.
**Learning:** `Math.random()` was primarily used in the codebase without falling back to cryptographically secure APIs if they were available in the current JavaScript runtime.
**Prevention:** Rely on direct feature detection of `crypto.randomUUID()` and `crypto.getRandomValues()` to generate secure random UUIDs and entropy, while safely falling back to `Math.random()` only when those aren't available. Avoid instantiating new arrays repeatedly within loops (such as using `crypto.getRandomValues()` inside a `String.prototype.replace` loop) and instead allocate a single byte array of the required entropy beforehand to avoid memory limits or performance bottlenecks.
