## 2024-04-02 - Unsafe Eval and Weak Random Number Generation
**Vulnerability:** The `guid()` implementation in `utils.ts` relied entirely on `Math.random()`, leading to weak predictability. Additionally, `nativeGlobal.ts` resorted directly to `eval("this")` to retrieve the global context, which poses a severe XSS/Code Execution risk in environments with strict CSPs or restricted access.
**Learning:** Security-critical functions like random generation and global object access must be resilient and utilize defense-in-depth principles. Bypassing modern capabilities (like `crypto`) just for compatibility compromises security.
**Prevention:** Implement proactive feature detection (`crypto.randomUUID`, `crypto.getRandomValues`) for randomness, with pre-allocation for performance. For `nativeGlobal`, explicitly check `globalThis`, `self`, `window`, and `global` before executing any eval. Use `@ts-ignore` judiciously to avoid TypeScript errors on environment-specific variables like `global`.
