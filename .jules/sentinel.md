## 2024-05-24 - Weak PRNG usage in `guid` generation
**Vulnerability:** The `guid()` utility in `js_libraries/lynx-runtime-shared/src/utils.ts` uses `Math.random()` to generate UUIDs, which is not cryptographically secure and may result in collisions, leading to insecure UUID generation.
**Learning:** Using `Math.random()` to generate UUIDs is a security risk because it does not provide sufficient randomness for generating secure and unique tokens. Relying on an insecure PRNG for token generation can compromise the unpredictability of the token, leaving it vulnerable to predictable patterns or brute force attacks. The `guid()` implementation should prefer the global `crypto.randomUUID()` method or fallback to `crypto.getRandomValues()` if possible.
**Prevention:** We should always use the standard `crypto` API available in modern JavaScript runtimes to generate random UUIDs. We must first verify the availability of the `crypto` API, fallback to the older implementation if it is completely unavailable.
