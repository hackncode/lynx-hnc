## 2024-06-18 - URL Scheme Validation Vulnerability
**Vulnerability:** The `openSchema` function in `explorer/homepage` passed user-provided URLs directly to the `NativeModules.ExplorerModule.openSchema` native method without any validation. This could allow an attacker to trigger arbitrary and potentially dangerous URL schemes (like `javascript:` or custom local schemes) natively, leading to XSS-like vulnerabilities or unauthorized access to native functionality.
**Learning:** React Native / Lynx environments can be vulnerable to client-side injection attacks when inputs are passed indiscriminately from the JS layer to native modules, particularly ones dealing with navigation or intents. Any URL opened through a native bridge must be strictly validated.
**Prevention:** Always implement a strict allowlist of URL schemes (e.g., `http:`, `https:`, `file:`, `lynx:`) using `startsWith` checks on the lowercased input before invoking native modules that open URLs or intents.
