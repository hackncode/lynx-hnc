## 2025-02-18 - [Fix Content Security Policy (CSP) Unsafe Eval Vulnerability]
**Vulnerability:** The application used `eval('this')` or `new Function('return this')()` to resolve the global object in `nativeGlobal.ts`, `ttConsole.ts`, `android-polyfill.js`, and `index.js` (lynx-promise). This triggers `unsafe-eval` violations in strict Content Security Policy (CSP) environments, potentially breaking functionality or increasing the attack surface if CSP is bypassed.
**Learning:** Hardcoded usages of `eval` and `new Function` were widespread for getting a reference to the global object, despite modern standard alternatives existing. This reveals a gap in the codebase regarding secure coding practices and CSP compliance, especially in polyfill and runtime initialization code.
**Prevention:** Always prioritize standard global object references (e.g., `globalThis`, `self`, `window`, `global`) before falling back to `Function` generation. Implement feature detection instead of blindly executing arbitrary strings.
